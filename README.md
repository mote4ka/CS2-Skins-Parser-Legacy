<h1>CS2 Skins Parser</h1>
<p>This code parse Lis-Skins and CSMarket to find best skins to buy and sell.</p>
<br>
<h2>Setup Giude</h2>
<p>Create config.py file in directory.</p>
<p>Set <i>usdrub</i> USD price from Lis-Skins. Also you need set <i>low_filter</i> and <i>high_filter</i> if you nedd to filter price (LEGACY). You can apply all filters what you need directly in Excel.</p>
<img width="466" height="164" alt="configsetup" src="https://github.com/user-attachments/assets/f5b372c8-8367-4f78-a45f-522e8eb67d0d" />
<br>
<h2>Using Guide</h2>
<p>Just run <i>run.bat</i>. Within a few second file <i>output.xls</i> will be created.</p>
<br>
<h2>Output</h2>
<p><i><b>Output example file</b></i></p>
<img width="991" height="613" alt="image" src="https://github.com/user-attachments/assets/700d7146-9443-4f5d-8fba-ccb239d17ab0" />
<p>By clicking on <i>Buy Price</i> or <i>Sell Price</i>, you will be redirected to Lis-Skins or CSMarket site.</p>
<br>
<h2>Output file overview</h2>
<p> Buy Price - price on Lis-Skins </p>
<p> Sell Price - best price on CSMarket (ask price)</p>
<p> Buy Order - instant sell price</p>
